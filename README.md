# Auto Chords

Android-приложение Auto Chords: круг аккордов, цифровой тюнер, локальный плеер и редактор аккордов.

Исходный интерфейс: `app/src/main/assets/index.html`.

Сборка: **GitHub Actions → Build Auto Chords APK**. После успешной сборки APK появляется в Artifacts и в разделе Releases (preview).

> Анализ аккордов в загруженных песнях — экспериментальный и требует проверки на слух.

> Debug APK подписан отладочным ключом, который может меняться между сборками. Для обновления поверх установленной версии нужен постоянный ключ подписи; при публикации стабильной версии необходимо настроить безопасное хранение ключа.

## Версия 0.2.0 — сетка аккордов 4×4

- Во время воспроизведения одновременно показаны **16 аккордов** в четырёх строках и четырёх столбцах.
- Подсветка перемещается по временным отметкам. После ячейки №16 экран автоматически показывает следующие 16 ячеек, без прокрутки страницы; при перемотке назад страница меняется обратно.
- По кнопкам слева и справа можно пролистывать сетку вручную.
- Для тестовой записи **Chris Rea — And You My Love** разметка получена повторным спектральным анализом. Воспроизводится только после выбора аудиофайла с устройства. **Разметка приблизительная**, точность не гарантирована.
- Аккорды и время их смены редактируются нажатием на ячейку. Правки сохраняются локально для файла по имени и размеру.
- По кнопке «Анализировать» можно пересчитать аккорды; перед заменой сохранённых изменений будет запрос подтверждения.

Сборка APK: GitHub Actions → Build Auto Chords APK; результат выкладывается в GitHub Releases, тег `preview`.

**Установка поверх предыдущей preview-версии может не сработать**, так как сборки подписаны разными отладочными ключами. Для постоянных обновлений нужна стабильная подпись.

## Версия 0.3.0 — редактор аппликатур и табы

- Удалён предустановленный демонстрационный трек и его встроенная разметка. Домашний экран и список локальных файлов пусты до импорта собственных записей.
- В редакторе аккордов доступен интерактивный гриф с 6 струнами, 5 видимыми ладами, переключением позиции, открытыми и заглушёнными струнами, пресетами распространённых аппликатур и синтезированным предпрослушиванием.
- Добавлена полноценная вкладка «Табы»: 6 струн, ноты/лады по аккордам, переключение блоков по 16 событий и автоматическая подсветка по времени воспроизведения. Нажатие на столбец открывает редактор соответствующего аккорда.
- Возможен ручной ввод табулатур в отдельное поле заметок. Изменённые аппликатуры сохраняются локально с привязкой к имени и размеру аудиофайла.
- **Важно**: создаваемые табы — это отображение аппликатур, **не** транскрипция фактической гитарной партии. Автоматические аккорды — экспериментальная оценка; требуются ручные уточнения.

Сборка APK публикуется в разделе [Releases](https://github.com/anderza/autochords/releases/tag/preview) после успешного GitHub Actions. Как и раньше, debug-подпись может меняться между сборками, поэтому обновление поверх предыдущего APK не гарантировано.

## Версия 0.4.0 — исправления распознавания аккордов

- Исправлена критическая ошибка кеша: прежде автоматическая разметка сохранялась как ручная, поэтому устаревшие или неверные результаты воспроизводились при повторном открытии трека. Теперь кешируются **только подтверждённые пользователем ручные изменения**; старые автоматические массивы игнорируются и анализируются заново.
- Спектральное распознавание улучшено: FFT 16384, выравнивание спектра, хрома по музыкальным высотам, басовые ноты, сглаживание по времени и последовательная оптимизация аккордов (Viterbi).
- Изменения аккордов оцениваются по звуковым кадрам ~0,32 с, сохраняются приблизительные временные отметки, не искусственные равномерные интервалы.
- Явно обозначены паузы («—») и сомнительные участки («?») — приложение не выдаёт их за уверенно распознанные аккорды.
- Семейства: мажор, минор, доминантсепт, минорный септ, maj7, уменьшённый и sus4. Септаккорды распознаются осторожно во избежание ложных результатов.
- Сетка 4×4, табулатуры, ручное редактирование и локальные файлы сохранены.
- Проверка алгоритма на синтезированной последовательности Am → F → C → G: правильный порядок и приблизительные моменты переходов.

**Ограничение:** спектральный анализ не является точной транскрипцией коммерческих аудиозаписей. Вокал, бас, ударные и гитарные эффекты могут исказить определение аккордов. Табулатуры показывают аппликатуры, не сыгранные партии.

## Версия 0.5.0 — горизонтальная лента аккордов

- В разделе «Локальные файлы» сетка 4×4 **заменена непрерывной горизонтальной лентой**. Предыдущие аккорды расположены слева и затемнены, текущий — крупный белый по центру, следующие — справа.
- Лента перестраивает положение по индексам временных событий, полученных из анализа аудио или отредактированных вручную; при перемотке сразу переходит к выбранному событию.
- Во время воспроизведения обновление активного аккорда происходит по `audio.currentTime` в `requestAnimationFrame` (дополнительно к `timeupdate`), а не по искусственному равномерному таймеру. Переход к следующему аккорду сдвигает ленту плавно.
- При нажатии на название аккорда плеер перематывает к его временной отметке. Кнопка «Править» открывает существующий редактор аккорда и его времени. Двойное нажатие на название тоже открывает редактор.
- Список табулатур, цифровой тюнер, круг тональностей и другие разделы сохранены.
- Тест синхронизации в Chromium: при 4,5 секунды на синтезированной последовательности Am → F → C → G подсвечен C, предыдущие Am/F слева; порядок автоматического анализа подтверждён на этом контрольном образце.

**Ограничение:** распознавание аккордов использует экспериментальный гармонический анализ `harmonic-v4`. Привязка ленты к рассчитанным меткам времени корректна, но названия и моменты переходов на сложных записях (вокал, ударные, бас, эффекты) могут быть неточными. Ошибки можно исправлять вручную.

**Подпись:** это preview debug APK; без постоянного ключа подписи установка поверх предыдущей версии не гарантирована.

## Версия 0.6.0 — студийный интерфейс в духе GarageBand

- Оформление интерфейса заменено на чёрный фон, оранжевые акценты, карточки композиции, сегментированные вкладки и компактные прямоугольные кнопки в iOS-стиле. Сохранены круг тональностей, цифровой тюнер, локальная библиотека и инструментальные настройки.
- Кнопка Play теперь содержит SVG-треугольник, геометрически центрированный внутри круглой кнопки; при проигрывании заменяется на симметричный значок паузы.
- В разделе «Текст» поиск текста по названию и исполнителю через публичный каталог LRCLIB: `https://lrclib.net/api/search`. Запись выбирается пользователем; если точное совпадение найдено по названию и исполнителю в имени файла, приложение может загрузить его автоматически. Неполные/неверные совпадения показываются как варианты, а не подставляются молча.
- Для синхронизированного LRC отображаются строки с временными метками, подсвечивается текущая строка, над ней показываются предварительно определённые аккорды по `audio.currentTime`. Если LRC-времени нет, точная привязка не заявляется. Также доступен ручной ввод текста/LRC.
- «Табы»: одна горизонтальная шестиструнная дорожка с названиями аккордов, позициями ладов, временными отметками и плавным оранжевым курсором. Автопрокрутка следует за проигрыванием и перемоткой, возможна ручная корректировка. Дополнительно можно включить синтезированное звучание аппликатур по мере смены аккордов.
- Android-иконка обновлена на собственный векторный знак с медиатором и гитарным грифом в оттенках оранжевого. Имя на рабочем столе — **AutoChords**.
- Проверены в Chromium: переключение вкладок, загрузка тестовой LRC-разметки, выделение текущего аккорда, обновление табулатуры и точное центрирование SVG Play; работа интерфейса Android требует проверки на устройстве.

**Ограничения:** текст доступен только при наличии соответствующего материала в каталоге и подключения к сети. Сервис и правообладатели определяют возможность использования текстов. Аккорды и отметки времени выводятся из экспериментального анализа аудио и не всегда верны. Табы основаны на аппликатурах аккордов, а не на точном выделении гитарной партии из записи. Отладочная подпись APK может мешать обновлению поверх прежней версии.

## Версия 0.7.0 — шестиструнные табы и тюнер

- На экране табов теперь шесть непрерывных линий в порядке **e B G D A E** и белые номера ладов согласно сохранённым аппликатурам. Нажатие на аккорд перематывает песню, двойное нажатие открывает редактор лада. Текущую позицию показывает оранжевый курсор; при перемотке он синхронизируется с `audio.currentTime`.
- Лишний текст под кнопкой «Анализировать» убран визуально; сообщения о ходе анализа сохранены для программ чтения с экрана.
- Тюнер переведён на поиск высоты звука по разностной функции с нормализацией (YIN), уменьшенной частотой анализа и фильтрацией от случайных скачков; добавлены понятные состояния для тишины, запрета доступа и включённого микрофона.
- На Android звуковой контекст запускается прямо из нажатия пользователя до запроса разрешения, чтобы снизить риск блокировки запуска после системного окна. При выходе из тюнера запись микрофона прекращается.
- Для мобильного экрана тюнер перестроен: кнопки «Микрофон», «Опорный тон», все шесть струн и частоты A4 помещаются на экране без длинной прокрутки.
- Контрольный тест в Chromium: синусоидальные ноты D2 (73,42 Гц), E2 (82,41), A2 (110), D3 (146,83), G3 (196), B3 (246,94), E4 (329,63) определяются с погрешностью менее 1,5%; тестовый поток микрофона 110 Гц отображается как A2. Проверен вывод аппликатур Am, C, G, Dm и отсутствие ошибок JavaScript.
- **Ограничение**: аппаратный микрофон на реальном Android-телефоне в тестовой среде не проверялся; уровень шума и режим доступа могут зависеть от устройства. Табы построены из аппликатур аккордов, не являются полной транскрипцией гитарной партии.

## Версия 0.8.0 — тональность, онлайн-текст, недавние записи

- Исправлена вкладка «Тональность»: после анализа всей записи вычисляется предполагаемая тональность по суммарному профилю 12 высотных классов и слабым признакам тоники из аккордов. На экране явно указывается приблизительность и уровень уверенности. При ручных поправках данные обновляются.
- Поиск текста через LRCLIB теперь использует метаданные ID3 MP3 (TIT2/TPE1), поиск по названию+исполнителю и запрос по ключевым словам. Пользователь может уточнить название и исполнителя. При ограничениях CORS в Android WebView доступен нативный HTTP-запрос только к публичному LRCLIB /api/search.
- Раздел «Недавние» теперь хранит импортированные файлы локально в IndexedDB, а не только их названия. Повторное нажатие открывает аудио сразу в плеере и запускает воспроизведение, включая повторные запуски приложения, если хранилище устройства сохранило файл.
- После выбора локального файла плеер запускается автоматически. Если браузер запрещает автовоспроизведение или на устройстве не хватает памяти для хранения аудио, приложение сообщает об ограничении; старые записи нужно импортировать один раз заново.
- Проверено в браузере на тестовых данных: определение предполагаемой тональности C для Am–F–C–G, работа списка вариантов LRCLIB, открытие сохранённого трека и переключение на экран плеера. Тест устройства Android и реальный сетевой ответ LRCLIB требуют отдельной проверки.

**Ограничения:** тональность и аккорды определяются спектрально, а не с гарантией правильной расшифровки. Наличие текста в LRCLIB не гарантируется; недоступность правообладателя или каталога не может быть обойдена. Повторное воспроизведение зависит от объёма локального хранилища; установочные debug APK с разными подписями могут не обновляться поверх предыдущих.

## Версия 0.9.0 — папка рядом с названием и более точная временная разметка

- В строке с названием выбранной песни значок ⓘ заменён на **оранжевую квадратную кнопку папки**. Она открывает системный выбор аудиофайла через существующий Android WebView FileChooser. Можно выбрать другой MP3, WAV или поддерживаемый аудиоформат, не возвращаясь на главный экран.
- Улучшен экспериментальный анализ гармонии `harmonic-v5.1`: спектральные окна пересчитываются с шагом ~0,16 сек вместо ~0,32 сек, 5-кадровое временное сглаживание вместо 7-кадрового; штраф смены аккорда скорректирован так, чтобы переходы реже задерживались.
- Моменты смены аккордов уточняются по локальной атаке звукового сигнала только при достаточно сильном всплеске; в остальных случаях остаётся спектральная оценка. Для стереофайлов уменьшен риск полного взаимного подавления противофазных инструментов.
- При выборе новой песни, пока предыдущая ещё анализируется, задача анализа для нового файла ставится в очередь и запускается после завершения старой.
- Контрольный тест на синтетической восьмиаккордовой записи Em–C–G–D–Am–F–C–G с нерегулярными длительностями: все восемь названий определены в правильном порядке; средняя абсолютная ошибка временных отметок переходов сократилась примерно с 0,29 до 0,12 сек. Тестовая четырёхаккордовая запись Am–F–C–G также распознана правильно; проверен выбор файла по новой кнопке.
- Дополнительная проверка: полноценный MP3 (5:30) успешно анализируется, результат включает 98 предполагаемых смен аккордов. **Это не тест точности на реальном произведении:** без эталонной транскрипции нельзя проверить правильность всех аккордов.

**Ограничения:** это не ML-транскрипция многодорожечной музыки. При вокале, эффектах и сложных гармониях остаются ошибочные названия и интервалы. Их можно исправлять через «Править». APK публикуется с отладочной подписью, обновление поверх другой debug-сборки может не сработать без одинакового ключа.

## AutoChords v0.9.1 — пауза, системный тюнер и упрощённый экран

- Новые композиции и файлы из «Недавних» при открытии **остаются на паузе** до нажатия Play.
- Android-тюнер использует системный `AudioRecord` с разрешением `RECORD_AUDIO`, а не только WebView `getUserMedia`. В браузере сохранён прежний механизм. При включении и выключении микрофона виден статус разрешения/сигнала, частота и отклонение в центах.
- Android `FLAG_KEEP_SCREEN_ON` предотвращает автоматическое выключение дисплея, пока приложение открыто на экране.
- Кнопки «+» и «↓ JSON» спрятаны рядом с «Анализировать», а лишние статические текстовые подсказки убраны. Динамические предупреждения микрофона и поиска текстов сохранены.
- Поиск текста: идентификация клиента LRCLIB в запросах, резервный источник Lyrics.ovh для песен с установленным исполнителем и Android-резервная сеть для обоих сервисов. Для Lyrics.ovh текст без временных меток; синхронизация по словам не заявляется.
- В тестах можно проверить синтетические ноты через анализатор браузера; реальный микрофон Android требует проверки непосредственно на телефоне. Вышедший APK — debug-сборка, обновление поверх старой установки зависит от подписи.

### Проверка
При первом запуске тюнера нажать «Микрофон», разрешить RECORD_AUDIO, сыграть открытую струну. Если звук не определяется, проверить разрешения приложения и прислать модель Android-устройства и надпись из статуса микрофона.


## Версия 0.9.2 — аккорды над словами и плавная синхронизация

- Убраны служебные надписи об источниках текстов LRCLIB/Lyrics.ovh, синхронизации и формате LRC. Пользователь видит текст песни и аккорды. Ошибки поиска остаются доступными.
- Каждая строка текста представлена словарными элементами, и аккорд расположен непосредственно над словом, а не отдельно в строке с равномерными промежутками.
- Поддержаны временные метки внутри текста вида <00:12.34> для конкретных слов (enhanced LRC). При обычных метках строк [00:12.34] позиция слова оценивается пропорционально длительности фразы, поэтому может не быть точной.
- «✎ Расставить» позволяет закрепить текущий аккорд над выбранным словом; правки сохраняются локально для композиции. Для текстов без временных меток автоматическое расположение над конкретными словами не заявляется — можно установить вручную.
- Лента аккордов теперь сдвигается плавно на каждом кадре, с плавной подстройкой позиции после точного перехода audio.currentTime через метку. При перемотке и паузе позиция пересчитывается немедленно.
- В разделе «Инструмент» добавлен «Сдвиг аккордов» с шагом 0,1 с (±3 с), позволяющий компенсировать задержку или опережение оценённой разметки. Значение сохраняется для трека и учитывается в ленте аккордов, табулатуре и словах текста.
- Изменения не обещают точного распознавания гармонии или реальных слов без детальной транскрипции и word-level временных меток. Уточнение расстановки доступно вручную.

## AutoChords v0.9.3 — Player и строи инструментов

- Нижняя навигация «Инструменты» заменена на «Player», открывающий текущий плеер без изменения состояния воспроизведения. Если песня не выбрана, показывает выбор аудио. Настройки доступны через шестерёнку.
- Бас: E1 A1 D2 G2, Drop D (D1 A1 D2 G2), 5-струнный B0 E1 A1 D2 G2 и полутон ниже Eb1 Ab1 Db2 Gb2. Укулеле: G4 C4 E4 A4, Low G (G3 C4 E4 A4), баритон (D3 G3 B3 E4).
- В настройках и в тюнере выбор строя и инструмента синхронизирован. Показаны реальные ноты с октавами, частоты, четыре, пять или шесть струн.
- Диапазон браузерного и нативного распознавания расширен до 29–475 Гц; для низких басовых нот требуется тихая комната и проверка на устройстве. У пианино — опорные C4 и A4, без обещания настройки всего фортепиано.
- Табулатуры остаются гитарными аппликатурами; отдельные табы для баса и укулеле пока не реализованы.
