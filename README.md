# Auto Chords

Android-приложение Auto Chords: круг аккордов, цифровой тюнер, локальный плеер и редактор аккордов.

Исходный интерфейс: `app/src/main/assets/index.html`.

Сборка: **GitHub Actions → Build Auto Chords APK**. После успешной сборки APK появляется в Artifacts и в разделе Releases (preview).

> Анализ аккордов в загруженных песнях — экспериментальный и требует проверки на слух.

> Debug APK подписан отладочным ключом, который может меняться между сборками. Для обновления поверх установленной версии нужен постоянный ключ подписи; при публикации стабильной версии необходимо настроить безопасное хранение ключа.

## Версия 0.2.0 — сетка аккордов 4×4

- Во время воспроизведения одновременно показаны **16 аккордов** в четырёх строках и четырёх столбцах.
- Подсветка перемещается по временным отметкам. После ячейки №16 экран автоматически показывает следующие 16 ячеек, без прокрутки страницы; при перемотке назад страница меняется обратно.
- По кнопкам слева и справа можно пролистывать сетку вручную.
- Для тестовой записи **Chris Rea — And You My Love** разметка получена повторным спектральным анализом. Воспроизводится только после выбора аудиофайла с устройства. **Разметка приблизительная**, точность не гарантирована.
- Аккорды и время их смены редактируются нажатием на ячейку. Правки сохраняются локально для файла по имени и размеру.
- По кнопке «Анализировать» можно пересчитать аккорды; перед заменой сохранённых изменений будет запрос подтверждения.

Сборка APK: GitHub Actions → Build Auto Chords APK; результат выкладывается в GitHub Releases, тег `preview`.

**Установка поверх предыдущей preview-версии может не сработать**, так как сборки подписаны разными отладочными ключами. Для постоянных обновлений нужна стабильная подпись.

## Версия 0.3.0 — редактор аппликатур и табы

- Удалён предустановленный демонстрационный трек и его встроенная разметка. Домашний экран и список локальных файлов пусты до импорта собственных записей.
- В редакторе аккордов доступен интерактивный гриф с 6 струнами, 5 видимыми ладами, переключением позиции, открытыми и заглушёнными струнами, пресетами распространённых аппликатур и синтезированным предпрослушиванием.
- Добавлена полноценная вкладка «Табы»: 6 струн, ноты/лады по аккордам, переключение блоков по 16 событий и автоматическая подсветка по времени воспроизведения. Нажатие на столбец открывает редактор соответствующего аккорда.
- Возможен ручной ввод табулатур в отдельное поле заметок. Изменённые аппликатуры сохраняются локально с привязкой к имени и размеру аудиофайла.
- **Важно**: создаваемые табы — это отображение аппликатур, **не** транскрипция фактической гитарной партии. Автоматические аккорды — экспериментальная оценка; требуются ручные уточнения.

Сборка APK публикуется в разделе [Releases](https://github.com/anderza/autochords/releases/tag/preview) после успешного GitHub Actions. Как и раньше, debug-подпись может меняться между сборками, поэтому обновление поверх предыдущего APK не гарантировано.
